# Отчёт о тестировании `CV-001`

## Задача

- Внутренний номер: `CV-001`
- GitHub Issue: не создавалась; изменения выполняются по прямому запросу пользователя
- Название задачи: заменить немецкий Lebenslauf и убрать английскую версию CV

## Области проверки

- документация
- структура проекта
- PDF

## Что проверено

- В `README.md` отсутствуют ссылка и строка английского CV.
- В `README.md` присутствует одна ссылка на немецкий Lebenslauf.
- Английский PDF удалён из репозитория.
- Немецкий PDF заменён переданным пользователем файлом.
- Новый PDF открывается и содержит две страницы A4.
- Обе страницы визуально проверены на читаемость, обрезку и наложения.

## Как проверено

- Выполнен скрипт `tests/checks/check-profile-cv.ps1`.
- SHA-256 опубликованного Lebenslauf сопоставлен с SHA-256 переданного файла.
- Структура PDF проверена через `pdfinfo` и `pypdf`.
- Обе страницы отрисованы в PNG через Poppler и просмотрены визуально.

## Результат
